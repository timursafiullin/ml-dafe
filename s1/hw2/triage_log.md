| CV F1 | Holdout F1 | Public F1 | Обучение на 6400 строках, с | Прогноз на 1 пациента, мс |
|---:|---:|---:|---:|---:|
| 0.7995 | 0.7930 | **0.80890** | 0.7539 | 8.9898 |

Время прогноза включает подготовку признаков. В таблице указана медиана по 100 вызовам `predict` на одной строке после прогрева.

## SUB-005. Смесь двух LightGBM

Файл [lightgbm_mix.csv](data/submissions/lightgbm_mix.csv). Для каждого пациента усреднил вероятности исходного LightGBM и поэтапной модели. Последняя сначала оценивает ESI-1, затем ESI-2 среди оставшихся пациентов, а для остальных различает ESI-3, ESI-4 и ESI-5. Веса обеих моделей равны. Отдельную поправку для ESI-2 проверил на внутренних фолдах и в итоговом варианте оставил коэффициент 1.

| Macro F1 | SUB-001 | Смесь |
|---|---:|---:|
| CV, среднее по трём разбиениям | 0.79609 | 0.80052 |
| Holdout | 0.79305 | 0.79643 |
| Public | 0.80890 | **0.81242** |

На каждом из трёх разбиений средний F1 вырос. По отдельным фолдам смесь выиграла в 10 сравнениях из 15. На holdout выигрыш пришёлся на ESI-3, ESI-4 и ESI-5, а F1 для ESI-2 снизился с 0.58359 до 0.57407. Для одного пациента смесь потребовала 17.70 мс по медиане. Относительно SUB-001 изменились 134 ответа из 5000. На Public смесь прибавила 0.00352 к SUB-001.

## SUB-006. Ансамбль с дополнительными признаками

Отправил [triage_next.csv](data/submissions/triage_next.csv). Усреднил вероятности SUB-005, LightGBM с частотами классов по жалобе и CatBoost с равными весами. Последним двум моделям добавил отношение пульса к систолическому давлению, пульсовое давление, отношение сатурации к частоте дыхания и индекс массы тела. Частоты для обучающих строк LightGBM считал по внутренним фолдам.

| Macro F1 | SUB-005 | SUB-006 | Разница |
|---|---:|---:|---:|
| CV, среднее по трём разбиениям | 0.80052 | 0.81033 | +0.00981 |
| CV, дополнительное разбиение (seed 2026) | 0.80205 | 0.81050 | +0.00845 |
| Holdout | 0.79643 | 0.80616 | +0.00973 |
| Public | 0.81242 | **0.82261** | **+0.01019** |

На первых трёх разбиениях ансамбль выиграл 14 фолдов из 15, на дополнительном — 4 из 5. На holdout больше всего вырос F1 для ESI-1, с 0.87234 до 0.90526. У 108 из 5000 тестовых пациентов изменился ответ относительно SUB-005. У SUB-006 лучший Public F1 среди отправок, на 0.01371 выше исходного LightGBM (SUB-001).
